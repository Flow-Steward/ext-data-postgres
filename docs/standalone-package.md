# Standalone PostgreSQL package

One installable extension owns PostgreSQL, its connection profiles, dataset/SQL contracts, vector operations, UI and native driver. Existing extension, connection and dataset identifiers remain stable. Version 1.4.0 adds pgvector to the same direct PostgreSQL project connection.

One pinned Toolbox native build combines driver-bound SQL parameters with opt-in managed vector endpoint/wire/result limits. Ordinary SQL and managed source behavior remains unchanged. Build provenance records both patch hashes, registered packages and native artifact hashes. Each AMD64 or ARM64 archive contains exactly its matching executable; no factory/template source is installed.
